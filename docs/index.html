خطط الأسبوع في SharePoint، الواجبات والتقييمات في Schoology، الحضور، رسائل أولياء الأمور على واتساب والإيميل، والمواد التعليمية — وكل حاجة بتتأكد منها وتتسجل بالإثبات.

Weekly plans in SharePoint, assessments and assignments in Schoology, attendance, parent messages by WhatsApp and email, and teaching materials — every action checked and kept with proof.

التسطيب في 3 خطوات

Install in 3 steps

1

نزّل البرنامج

Download

اضغط زرار التحميل. هينزل ملف واحد اسمه TeachersAssistant-Setup.exe (حوالي 62 ميجا).

Press Download. One file, TeachersAssistant-Setup.exe (about 62 MB), is saved.

2

افتح الملف

Open it

افتحه من التنزيلات. لو ظهرت شاشة ويندوز الزرقا اضغط More info ثم Run anyway (الصورة تحت). مش محتاج صلاحيات Admin.

Open it from Downloads. If Windows shows the blue screen, press More info, then Run anyway (picture below). No admin rights needed.

3

ابدأ

Start

البرنامج يفتح لوحده: اعمل حسابك، سجّل دخول المعارف مرة واحدة، واكتب الكود DEMO عشان تجربه 14 يوم.

The app opens by itself: create your account, sign in to Maarif once, and type the code DEMO to try it for 14 days.

لو ويندوز قال "Windows protected your PC"

If Windows says "Windows protected your PC"

دي رسالة عادية لأي برنامج جديد مش موقّع من شركة كبيرة. البرنامج آمن: بيتسطب في حسابك أنت بس، ومش بيطلب صلاحيات.

This is normal for a new program that is not signed by a big company. The app is safe: it installs for your Windows user only and asks for no admin rights.
